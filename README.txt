Keep everything in this folder together. The pages link to each other and to
the assets folder, so moving one file on its own will break its links.

To view it: double-click index.html.

To put it online (free, about a minute):
  1. Go to https://app.netlify.com/drop
  2. Drag this whole folder onto the page.
  3. You get a live link. Sign up (free) to keep it and rename the address.

To update it later, drag the updated folder onto your site's "Deploys" page in Netlify.
